1. 로그인하기

  1. 인터넷 브라우저(크롬 권장)에서 https://jmt-snug.github.io/online-worksheets/에 접속합니다.
  2. 학교 구글 계정(아이디@snu-g.ms.kr)으로 로그인합니다.
  3. 개인 구글 계정으로 로그인하면 학습지가 열리지 않거나 기록이 남지 않습니다. 반드시 학교 계정을 사용하세요.
💡 어느 기기에서든 OK기록은 계정에 저장되므로 학교 태블릿, 집 컴퓨터, 휴대폰 어디서 로그인해도 이어서 풀 수 있습니다.

2. 학습지 찾기와 잠금 표시

로그인하면 학년·영역별 단원 카드가 보입니다. 단원을 누르면 학습지 목록이 나옵니다.

2-1. 학습지 상태 표시

표시뜻
미시작아직 풀지 않은 학습지
진행 중 (3/10)풀다가 멈춘 학습지 — 이어서 풀 수 있어요
완료끝까지 다 푼 학습지
🔒 잠금선생님이 아직 열어 주지 않은 학습지 — 수업 진도에 맞춰 열립니다

2-2. 파트가 있는 학습지

  • 긴 학습지는 여러 파트로 나뉘어 있고, 문제 번호 줄 위에 파트 이름(🔓 열림 / 🔒 잠김)이 보입니다.
  • 잠긴 파트의 문제는 클릭할 수 없습니다. 열린 파트를 다 풀면 선생님이 다음 파트를 열어 줄 때까지 기다리면 됩니다.
  • 선생님이 파트를 열면 화면에 "🔓 ○○ 파트가 열렸어요!" 알림이 바로 뜹니다 (새로고침 필요 없음).

3. 문제 풀기

3-1. 답 입력과 채점

  • 답을 입력하고 확인 버튼을 누르면 바로 채점됩니다.
  • 틀리면 다시 도전할 수 있습니다. 정답을 맞혀야 다음 문제로 넘어가는 것이 기본이에요.
  • 순서쌍은 (3,4)처럼 괄호와 쉼표로 입력합니다. 띄어쓰기는 있어도 괜찮습니다.

3-2. 화면에 필기하기 (연습장)

  • 문제 옆과 아래의 빈 공간은 연습장입니다. 마우스·터치·펜으로 문제 위에 직접 풀이를 쓸 수 있습니다.
  • 필기는 학습지마다 저장되어 다시 들어와도 남아 있습니다.
💡 중간에 그만둬도 저장돼요풀던 내용은 자동 저장됩니다. 창을 닫았다가 다시 로그인하면 이어서 풀 수 있어요.

4. 그래프 문제와 선생님 채점

  • 그래프 문제는 좌표평면(또는 수직선) 위에 직접 점을 찍거나 선을 그려서 답합니다.
  • 그린 답안은 제출되면 선생님이 직접 확인하고 채점합니다. 바로 정답 여부가 나오지 않아도 기다리면 됩니다.
  • 선생님이 채점하거나 첨삭·피드백을 남기면 화면 위 종(🔔) 아이콘에 알림이 표시됩니다. 알림을 누르면 그 문제로 바로 이동해 결과와 선생님 글씨를 볼 수 있습니다.
💡 알림은 기기마다 따로알림 표시는 기기별로 저장됩니다. 다른 기기에서 로그인하면 같은 알림이 한 번 더 보일 수 있어요.

5. VOCA(용어)와 시험지

5-1. VOCA 학습지

  • 수학 용어를 암기하는 학습지입니다. 통과하면 PASS 횟수가 기록됩니다.
  • 여러 번 반복해서 PASS 횟수를 쌓을 수 있습니다.

5-2. 시험지

  • 📝 표시가 있는 학습지는 제한 시간이 있는 시험지입니다. 시작하면 타이머가 흘러갑니다.
  • 모든 문제에 답을 적고 제출하면 한 번에 채점되어 점수가 나옵니다.
⚠️ 시험 중 새로고침 금지!시험지를 푸는 도중 새로고침(F5)하거나 창을 닫으면 타이머가 처음부터 다시 시작됩니다. 시험이 끝날 때까지 절대 새로고침하지 마세요.

6. 꼭 지켜야 할 것

상황이렇게 하세요
학습지가 🔒 잠겨 있어요수업 진도에 맞춰 선생님이 열어 줍니다. 기다리거나 선생님께 여쭤 보세요.
다 풀었는데 완료 표시가 안 떠요새로고침한 뒤 다시 확인하고, 그래도 안 되면 선생님께 말씀드리세요.
로그인이 안 돼요학교 계정(@snu-g.ms.kr)인지 확인하세요. 다른 구글 계정이 로그인되어 있으면 로그아웃 후 다시 시도하세요.
그림(이미지)이 안 보여요새로고침해 보고, 계속 안 보이면 선생님께 알려 주세요.
시험지 시간이 이상해요새로고침하면 타이머가 초기화됩니다. 문제가 생기면 바로 선생님께 말씀드리세요.

궁금한 점은 수학 선생님께 물어보세요. 🙂

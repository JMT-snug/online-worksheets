2. 학습지 홈 (index) — 학급별 잠금 관리

2-1. 학습지 카드와 학급 버튼

단원 카드를 누르면 학습지 목록이 나옵니다. 교사에게는 각 학습지 카드 아래에 잠금 관리 버튼 줄이 표시됩니다.

  • 🔒 빨강 = 그 반에게 잠겨 있음 · 초록 = 열려 있음
  • 버튼의 색 채움 정도는 그 반의 완료율입니다 (30% 미만 테두리만 → 80% 이상 전체 채움). 지나간 학습지를 잠가도 완료율은 계속 확인할 수 있습니다.
  • 담당 학급 버튼을 클릭하면 잠금↔해제가 즉시 전환됩니다. 다른 반 버튼은 흐리게 표시되며 조회만 가능합니다.
⚠️ 전체 공개 상태의 학습지"🔓 전체 공개" 상태의 학습지는 모든 반이 접근 가능한 상태이며, 여기서 반별 잠금을 시작하는 것(전체 공개→잠금 전환)은 기본 교사만 할 수 있습니다. 담당 학급만 잠그고 싶은데 학습지가 전체 공개 상태라면 기본 교사에게 요청해 주세요.

2-2. 파트 잠금 (🧩 표시가 있는 학습지)

문항이 여러 파트로 나뉜 학습지는 수업 진행에 맞춰 파트를 순서대로 열 수 있습니다.

  1. 학습지 목록에서 담당 학급 버튼을 눌러 반을 해제하면 첫 파트가 자동으로 열립니다.
  2. 학습지를 열면 문제 화면 상단 문제 번호 줄에 파트 이름 칩(🔓/🔒)이 보입니다.
  3. 파트 칩을 클릭하면 반별 잠금 팝업이 열리고, 담당 학급의 파트를 클릭해 열거나 잠글 수 있습니다.
  4. 파트를 열면 학생 화면에 새로고침 없이 "🔓 ○○ 파트가 열렸어요!" 알림이 즉시 표시됩니다.

3. 교사 관리 (teacher) — 학생 현황 조회

왼쪽 사이드바에서 화면을 전환합니다. 담당 교사에게는 담당 학급 학생의 데이터만 표시됩니다.

메뉴내용
📊 현황판학급별 학습지 완료 현황 비교 (히트맵)
👥 학생 목록학생별 진도율(완료/전체 %)·평균 정답률. 학급 필터와 정렬 지원
학생 상세학생 개인의 학습지별 기록. 이전/다음 버튼으로 학생 간 바로 이동
학습지별 현황사이드바에서 학습지를 선택하면 반별 제출·정답률·문항별 오답 확인
🏫 학급 관리담당 학급 명단 확인 · 학생 추가/삭제
ℹ️ 진도율 집계 기준진도율은 일반 학습지(진도율 반영 ON)만 집계하며 VOCA·시험지는 제외됩니다. 분모는 같은 반에서 한 명이라도 시작한 학습지 수입니다.
💡 전·입학 등 명단이 바뀌었을 때🏫 학급 관리에서 담당 학급의 학생을 직접 추가/삭제할 수 있습니다 (아이디만 입력하면 도메인이 자동으로 붙습니다). 명단을 수정하면 잠금 학습지의 허용 목록도 자동으로 다시 계산됩니다. 학급 자체를 만들거나 없애는 것은 마스터 계정만 가능합니다.

4. 그래프 채점 (scoring)

학생이 좌표평면·수직선에 직접 그린 답안은 자동 채점이 되지 않으므로 이 화면에서 직접 채점합니다. 담당 교사에게는 담당 학급 학생의 답안만 목록에 나타납니다.

4-1. 채점 순서

  1. 상단에서 학습지 → 문항을 선택합니다 (그래프 문항이 있는 학습지만 목록에 나옵니다).
  2. 반 필터·상태 필터(전체/미채점/오답/정답)로 채점할 대상을 좁힙니다.
  3. 격자 위에 겹쳐 보이는 학생 답안을 확인하고 필요하면 펜 도구로 첨삭을 그립니다 (마우스·터치·태블릿 펜 지원).
  4. 피드백 텍스트를 입력할 수 있습니다 (입력창을 벗어나면 자동 저장).
  5. 판정 버튼(⭕ 정답 / ❌ 오답 / 보류)을 누르면 자동 저장되고 다음 학생으로 넘어갑니다. 별도의 저장 버튼은 없습니다.

4-2. 단축키

키동작
← / →이전 / 다음 학생
1 또는 o정답 판정
2 또는 x오답 판정
💡 채점 결과는 학생에게 알림으로채점하거나 첨삭·피드백을 남기면 학생의 학습지 홈 헤더 종(🔔)에 알림이 표시되고, 학생이 클릭하면 해당 문항으로 바로 이동합니다.

학생이 답안을 다시 그린 경우 🔄 새로고침 버튼으로 최신 답안을 다시 불러올 수 있습니다.

5. 학습지 편집 (edit)

편집기는 권한 제한 없이 모든 교사가 사용할 수 있습니다. 주요 기능만 간단히 소개합니다.

  • 학습지 만들기: 단원을 고르고 학습지를 추가한 뒤 문항을 작성합니다. 수식은 LaTeX($...$)를 지원합니다.
  • 문항 유형: 단답형(대안 정답 등록 가능), 선택형, 단계형, 그래프(좌표평면/수직선 범위 지정), 이미지 문항 등. 학습지 유형으로 일반/VOCA/시험지(배점·제한시간)를 선택할 수 있습니다.
  • 파트 나누기: 문항 목록에서 🧩 버튼을 누르면 그 문항부터 새 파트가 시작됩니다. 구분선에서 이름 수정(✏️)·삭제(✕)가 가능합니다.
  • 발행 상태: 준비 중(draft) → 발행(공개) / 잠금. 잠금 상태여야 학급별·파트별 잠금이 작동합니다.
  • 이미지: Google Drive에 업로드된 이미지를 문항에 넣을 수 있습니다.
⚠️ 편집 시 주의여러 교사가 같은 학습지를 동시에 편집하면 나중에 저장한 내용으로 덮어써질 수 있습니다. 다른 교사가 만든 학습지를 수정할 때는 미리 협의해 주세요.

6. 오류 신고 (⚠️)

  • 학습지 홈(index) 오른쪽 아래의 ⚠️ 오류 신고 플로팅 버튼으로 누구나(학생·교사) 화면 오류를 신고할 수 있습니다.
  • 신고 절차: ⚠️ 오류 신고 클릭 → 오류 위치 클릭(빨간 동그라미) → 설명 입력 → 보내기. 현재 화면 캡처와 콘솔 기록이 함께 저장됩니다.
  • 학생이 "화면이 이상하다"고 하면 그 자리에서 새로고침하지 말고 먼저 오류 신고를 하게 해 주세요 — 오류 상황이 그대로 전달되어 해결이 빨라집니다.
  • 접수된 신고는 기본 교사가 별도 관리 페이지에서 확인하고 수정 여부를 관리합니다.

7. 자주 묻는 질문과 주의사항

질문답변
학습지를 풀어 봤는데 내 기록이 남나요?남지 않습니다. 교사 계정의 풀이는 저장되지 않습니다 (미리보기 전용).
담당이 아닌 반 학습지도 볼 수 있나요?열람(미리보기)은 가능합니다. 잠금 조작·기록 조회·채점만 담당 학급으로 제한됩니다.
학생이 "다 풀었는데 기록이 없다"고 해요.학생에게 로그인 상태를 확인하고 새로고침 후 다시 확인하게 해 주세요. 반복되면 기본 교사에게 알려 주세요.
시험지 응시 중 주의할 점은?학생이 새로고침하면 타이머가 초기화됩니다. 응시 전 "새로고침 금지"를 꼭 안내해 주세요.
교사 메뉴가 안 보여요.담당 교사 지정이 안 된 계정입니다. 마스터 계정(rapidwing) 선생님께 지정을 요청하세요.
학급 명단·담당 교사 변경은?담당 학급의 학생 명단은 🏫 학급 관리에서 직접 수정할 수 있습니다. 학급 추가·삭제와 담당 교사 지정은 마스터 계정 선생님께 요청하세요.
